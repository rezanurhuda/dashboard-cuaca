🌤️ Dokumentasi API Dashboard Cuaca

Seluruh endpoint data cuaca global diambil dari WeatherAPI.com

NOTE: API ini hanya mendukung metode GET. Tidak ada endpoint untuk POST, PUT, atau DELETE.

GET /current.json

Mendapatkan data cuaca saat ini

URL: https://api.weatherapi.com/v1/current.json

Parameter:

Parameter Wajib Tipe Deskripsi Contoh
key ✓ string API Key 1234567890abcdef
q ✓ string Nama Lokasi Bekasi
days int Jumlah Perkiraan Hari 3
aqi string Kualitas Udara (yes/no) no
alerts string Peringatan (yes/no) no

Contoh Request:

GET /current.json?key=API_KEY&q=Bekasi&days=3&aqi=no&alerts=no

GET /history.json

Mendapatkan data cuaca historis (hingga 1 tahun kebelakang)

URL: https://api.weatherapi.com/v1/history.json

Parameter:

Parameter Wajib Tipe Deskripsi Contoh
key ✓ string API Key dari WeatherAPI key=1234567890abcdef
q ✓ string Lokasi (nama kota, kode, atau koordinat) q=Paris
q=48.8566,2.3522
dt ✓ date Tanggal (format: YYYY-MM-DD) dt=2025-06-25
end_dt date Tanggal akhir rentang (opsional) end_dt=2025-06-30

GET /history.json?key=API_KEY&q=Bekasi&dt=2025-06-20&end_dt=2025-06-30

Kode Error

Kode Deskripsi Solusi
400 Parameter tidak valid Periksa format parameter (misal: format tanggal YYYY-MM-DD)
401 Autentikasi gagal Periksa API key dan status akun
403 Akses dilarang Akun tidak memiliki akses ke fitur ini
1006 Lokasi tidak ditemukan Periksa parameter 'q'
2008 Parameter 'days' melebihi batas Maksimal 14 hari untuk akun free
9000 Limit request tercapai Tunggu hingga limit reset (1 juta/bulan untuk akun free)
